WaterLauncher 1.2 makes problems easier to report, backs up saves after games you start elsewhere, and makes releases safer to cut.

**Reporting a problem**

- *Settings → About → Copy diagnostics* puts a report on the clipboard: versions (WaterLauncher, Windows, WebView2, Syncer), your settings, what the library holds, the controller, add-ons, updates, the last crash and the end of the log. It holds no keys or account names, and your user folder is shortened to `%USERPROFILE%`.
- *Report a problem* opens a new GitHub issue to paste it into.
- If the interface won't open at all, `WaterLauncher.exe --diagnostics` writes the same report to your desktop.
- When WaterLauncher crashes, what went wrong is kept (`crash-previous.log` next to the log) and it tells you at the next start.
- Errors inside the interface now reach the log too.

**Saves after games started elsewhere**

- A game from your library you started through Steam or a shortcut now gets a Syncer backup right when it closes, like a game started from WaterLauncher, instead of at Syncer's next scheduled backup a few hours later. Same setting: *Back up saves after playing*.

**For developers**

- `go run ./tools/release cut vX.Y.Z --pr N` releases from `main` one checked step at a time (tag, notes, clean and current `main`, merged pull request, green CI, version commit, tag, CI, signing and publishing) and stops at the first failing check ([docs/RELEASING.md](https://github.com/ApolloF/WaterLauncher/blob/main/docs/RELEASING.md)).
- CI installs every build silently, starts it in the tray, closes it with `--quit` and uninstalls it.
