WaterLauncher 1.1 notices games you start elsewhere, scans faster, uses less memory, and only accepts updates signed with a key that never leaves the maintainer's PC.

**Games started outside WaterLauncher**

- Start a game from your library through Steam, a desktop shortcut or its folder, and WaterLauncher notices: its playtime counts, the PS button opens the overlay, and WaterLauncher lets go of the controller while the game has it.
- It notices through Windows telling it which window came to the front: nothing is polled and nothing is injected into the game.
- WaterLauncher's own window stays as it was: it isn't closed for such a game, nor opened when it ends.
- *Settings → Big picture → While playing → Notice games started elsewhere* (on by default). Hidden games are never noticed.

**Faster scans**

- WaterLauncher remembers what it found in each game folder (Steam emulators, the program to start) and only looks again when something in the folder changed, or once a day. Repeat scans here went from 63 ms to 18 ms; with 100 large game folders, from about 0.8 s to 8 ms.

**Less memory**

- The game database (about 15 MB in memory) is let go a couple of minutes after a scan and read again when the next one needs it. WaterLauncher in the tray: 79 MB → 62 MB here.
- GOG Galaxy's library is read a page at a time instead of whole.

**Signed updates**

- Every release now carries `SHA256SUMS` and `SHA256SUMS.sig`. The signature is made with a key kept offline, away from GitHub, and covers the version number too. From this version on, the updater installs only files listed in a correctly signed `SHA256SUMS`. So even someone who took over the GitHub account couldn't push an update to you.
- Updating from 1.0 to 1.1 still works as before: 1.0 checks the SHA-256 published with the release.

**For developers**

- `tools/release`: `keygen`, `backup`, `restore`, `publish <tag>`, `verify <tag>`. Tags now create draft releases; `publish` signs and publishes them ([docs/RELEASING.md](https://github.com/ApolloF/WaterLauncher/blob/main/docs/RELEASING.md)).
- CI is ready for SignPath code signing, including a separately built, signed uninstaller ([docs/SIGNING.md](https://github.com/ApolloF/WaterLauncher/blob/main/docs/SIGNING.md)).
- `WL_HEAPPROFILE=<file>` logs memory use and writes heap profiles.
