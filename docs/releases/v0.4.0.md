Playing: WaterLauncher now starts your games, follows them while they run, and gets out of the way.

**Launching**

- Store games start through their store (Steam, Epic, GOG Galaxy, Ubisoft, EA, Battle.net, Xbox). Everything else starts from its own program, without a shell, in its own folder. A game that needs administrator rights shows Windows' own prompt.
- The launch shows each step before the game starts. A step can be skipped. From v0.5 Syncer's save sync runs here too.
- `WaterLauncher.exe --play <id>` starts a game straight from a shortcut, without opening the interface first.

**Playtime**

- WaterLauncher follows the game's processes: the program it started, anything that program starts, and anything running from the game's folder. Launchers that hand over to the game are covered, and so are games started through a store.
- Playtime is saved every minute and when the game exits. Time while the PC sleeps isn't counted.
- Details show *Playing · 12:34* while a game runs, with a button to quit it (click twice; unsaved progress is lost).

**Game mode**

- While a game runs, the interface closes to free its memory (the WebView alone takes about 400 MB; the core stays under 50 MB). It comes back when the game exits, in the same mode, with a short summary in big picture.
- WaterLauncher stays in the tray meanwhile: click the icon to open it sooner. Closing the window yourself still quits WaterLauncher, except while a game runs.
- Both are in Settings, Big picture, *While playing*.

**Controller while playing**

- WaterLauncher lets go of the controller while a game runs. It keeps only a passive listener for the PS / Xbox button: it never rumbles, never changes the lightbar and never switches a DualSense or DualShock 4 into its enhanced report mode, so games get the controller exactly as they expect. The listener can be turned off.
- **The PS / Xbox button opens the overlay** over the game: time played, controller battery, back to the game, open WaterLauncher, or quit the game. The overlay is a separate topmost window; nothing is injected into games, so anti-cheat is unaffected. It shows over borderless and windowed games; exclusive full-screen games may minimise.
- If Steam also opens on the PS button, turn off Steam's guide-button shortcut.

**Steam Input for games without DualSense support**

- In **Auto**, a game that supports Xbox controllers but not PlayStation ones starts through Steam Input when a PlayStation controller is in use, so the DualSense works as an Xbox controller. Games with DualSense or DualShock support, or that ship Sony's library or SDL, start directly. *Native* and *Steam Input* force one or the other.
- WaterLauncher adds a non-Steam shortcut for the game to Steam (in a *WaterLauncher* collection) and starts it through Steam. Steam only reads new shortcuts when it starts, so the first time WaterLauncher asks whether to restart Steam, start without Steam Input, or cancel. Games set to Steam Input are added together, so Steam restarts once.
- Before changing `shortcuts.vdf` for the first time, WaterLauncher keeps a copy next to it (`shortcuts.vdf.waterlauncher-backup`).
- Steam Input for non-Steam games follows Steam's own controller settings (*Enable Steam Input for PlayStation controllers*).

**Please test**

- A game with a DualSense over USB and over Bluetooth: the PS button opens the overlay, and the game's own DualSense features (adaptive triggers, haptics, lightbar) still work while WaterLauncher runs.
- A game set to Steam Input: the restart question, the shortcut in Steam, and the controller acting as an Xbox pad in the game.
- A game that starts through a launcher (Ubisoft, EA, Rockstar): playtime is counted for the game, not only the launcher.
